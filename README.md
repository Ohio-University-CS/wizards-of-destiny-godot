# WIZARDS OF DESTINY

## THE EPIC SPELL-SLINGING ROGUELIKE

---

### DESCRIPTION

Wizards of Destiny is a deckbuilding roguelike where you play as Bill the Wise, a Wizard cursed to come back to life endlessly to fight the evil forces trying to take over his world.

---

### FEATURES

- A starter deck to introduce players to gameplay
- A forest level to battle various enemies
- 15 unique items allow you to alter each run
- A shop system to upgrade your deck

---

### INSTALLATION / HOW TO RUN

To install:
- Go to the latest release
- Download the executable zip file
- Unzip
- The executable file will run the game

Alternatively, check out the game on Itch.io: https://logmiller13.itch.io/wizards-of-destiny

---

### KNOWN ISSUES

- Magician Deck is not 100% implemented, and some cards are a woork in progress
- Enchanted Forest does not have all enemies implemented
- Almost all sprites are still placeholders
